# Tip Sheet Quality Review

This pass reviewed the converted help-site articles for unnecessary screenshots, badly placed callouts, rough conversion language, missing context, and weak task structure.

## What Changed

- Removed non-instructional screenshot artifacts:
  - Standalone number-dot images imported from Word.
  - Tiny icon-only crops where the surrounding screenshot or step text already identifies the action.
  - Duplicate toolbar/export crops where one image was enough.
- Rewrote rough converted pages into web-native help articles:
  - Added `Before You Begin` sections where the action affects assignments, transcripts, rosters, due dates, certificates, or learner status.
  - Replaced fragmented Word instructions with direct task steps.
  - Removed duplicate "This guide explains..." intros.
  - Replaced generic screenshot alt text on rewritten pages with useful descriptions.
  - Removed end-user noise about checking the source tip sheet.
- Preserved useful screenshots:
  - Kept full UI context screenshots when they show where the user is in Cornerstone.
  - Kept small screenshots only when they identify a specific button, field, menu, or status that matters.
  - Kept the scanned Common Reports PDF pages because the source is image-based.
- Cleaned the older Ongoing Competency 2026 reference section:
  - Localized broken SharePoint image references.
  - Fixed obvious leftover wording typos.

## Review Notes

- `reports-common-reports.md` remains a scanned-page reference because the PDF source did not contain extractable text.
- The older Ongoing Competency 2026 pages remain reference material rather than fully rewritten tip sheets.
- The next highest-value human review is content-owner validation: confirm current Cornerstone labels, permissions, and process policy for learner-impacting actions.
