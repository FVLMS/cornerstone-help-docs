# Print a Certificate from a Curriculum

Use this guide to print a certificate for a specific learning item inside a curriculum.

## Before You Begin

- Use this workflow when you need the certificate for an individual learning object inside the curriculum.
- Do not select the main **View Certificate** button if you need a certificate for a specific item. That button opens the curriculum certificate.
- The curriculum does not need to be fully complete if the specific learning item is complete and has a certificate.

## Steps

1. From the LMS home page, go to **My Transcript**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-print-certificate-from-curriculum/step-01.png" alt="My Transcript link from the learner home page">

2. Use **Training Status** to find the curriculum.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-print-certificate-from-curriculum/step-02.png" alt="Transcript page with curriculum item">

3. Open the dropdown next to **View Certificate** and select **Open Curriculum**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-print-certificate-from-curriculum/step-03.png" alt="View Certificate dropdown for a curriculum">

   <img class="guide-image guide-image--small" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-print-certificate-from-curriculum/step-04.png" alt="Open Curriculum option in the dropdown">

4. Select the specific learning item.
5. Open that item's dropdown and select **View Certificate**. Do not select **Request**, because that can assign a new instance of the training.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-print-certificate-from-curriculum/step-05.png" alt="Learning item dropdown inside a curriculum with View Certificate">

6. Print or save the certificate from the certificate window.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-print-certificate-from-curriculum/step-06.png" alt="Certificate window for a learning item inside a curriculum">

## Notes

- If **View Certificate** is not available for the learning item, confirm the item is complete.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
