# Create a Video Lesson

Use this guide to create a video learning object that can stand alone or be added to a curriculum.

## Before You Begin

- Confirm whether the video will be uploaded as a file or embedded from YouTube.
- Supported uploaded formats include `.mpg`, `.mpeg`, `.wmv`, `.flv`, `.m4v`, and `.mp4`.
- Prepare the title, description, subject, owner information, and expected training hours before starting.

## Steps

1. Go to **Menu > Content Management > Catalog > Content Manger**.
2. Click **Create New Training** and scroll down to select **Video**.
3. Complete the required fields:
   - **Title**
   - **Training Hours**

     : enter the video length.
   - **Description**
   - **Credits**

     , if contact hours are offered.
   - **Subjects**
4. Choose how the video will be added:
   - **Upload a New Video**

     : attach the video file and wait for upload processing.
   - **Embed a Video**

     : 1) change content type to

     **Embed**

     and then 2)

     paste the URL

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/content-create-video-lesson/CreateVideo1.png" alt="Upload a New Video option">
5. Complete the other recommended fields:
   - In

     **Custom Fields**

     , add Objectives, audience description, and the owner's name and email, along with any other relevant information
   - **Availability**

     : set by default to all users. If availability should be restricted, delete the existing group and add the custom availability settings
   - In

     **Advanced Settings**

     a requirement for electronic signature can be added
6. Confirm the video details and select **Publish** if the video is ready to be assigned or select **Save as Draft** if not.
