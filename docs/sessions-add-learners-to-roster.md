# Add Learners to a Session Roster

Use this guide to add one or more learners to an instructor-led training session roster.

## Before You Begin

- Confirm the correct event and session date before adding learners.
- Check the enrollment count and registration deadline. Do not add learners to a full session or a session past the registration deadline unless the LMS team has approved it.
- Learners added before the session start time usually receive a confirmation email. Learners added after the start time may not.

## Add Learners

1. From the LMS home page, open the main menu.

2. In **Content Management**, select **Manage Events & Sessions**.

   <img class="guide-image guide-image--small" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-add-learners-to-roster/step-02.png" alt="Content Management menu with Manage Events and Sessions">

3. Search for the event by **Event Name**.
4. In the search results, select **View Sessions**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-add-learners-to-roster/step-05.png" alt="Manage Events and Sessions search results with View Sessions">

5. Find the correct session and select **Roster**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-add-learners-to-roster/step-07.png" alt="Session list with Roster action">

6. In the **Parent Roster** user section, select **Add Users**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-add-learners-to-roster/step-08.png" alt="Parent Roster user section with Add Users button">

7. In **Select User**, search by learner name or ID.
8. Select **Add** for each learner, then select **Done**.

<img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-add-learners-to-roster/step-12.png" alt="Select User window with learner search results">

9. Review the pending learners and select **Add Pending Users to Roster**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-add-learners-to-roster/step-13.png" alt="Roster page with Add Pending Users to Roster button">

10. Confirm the learners show **Registered** and that the session appears on their transcripts.

## Remove a Learner

1. From the session roster, open the learner's **Options** ellipses menu.
2. Select **Remove Users**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-add-learners-to-roster/step-14.png" alt="Roster learner Options menu with Remove Users">

3. In **Withdraw Registration**, select the withdrawal reason, enter a comment, and select **Submit**.
4. Confirm the learner is withdrawn from the session and the transcript reflects the updated status.

## Notes

- This page is the multi-learner version of the roster workflow.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
