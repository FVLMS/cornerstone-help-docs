# Track Interest as an ILT Admin

Use this guide to review learners who requested notifications for future sessions.

## Steps

1. Go to **Menu > Content Management > Manage Events & Sessions**.

   <img class="guide-image guide-image--small" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-interest-tracking-ilt-admins/step-01.png" alt="Content Management menu with Manage Events and Sessions">

2. Select **Interest Tracking**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-interest-tracking-ilt-admins/step-02.png" alt="Manage Events and Sessions page with Interest Tracking button">

3. Review the event list. The list includes:
   - **Event Name**
   - **Interested Users**
   - **Confirmed Future Sessions**
4. Search for a specific event if needed.
5. Select **View** to see the learners tracking interest for that event.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-interest-tracking-ilt-admins/step-03.png" alt="Interest Tracking event list with View option">

6. Review learner details, including learner name, user ID, division, position, selected location preferences, comments, signup date, and whether matching sessions exist.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-interest-tracking-ilt-admins/step-04.png" alt="Interest Tracking learner list with preferences and comments">

## Notes

- Export the list when you need to plan new sessions or follow up with interested learners.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
