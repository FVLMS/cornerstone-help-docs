# Edit Validation Details

Use this guide to edit validation details for a checklist line item.

## Before You Begin

- Confirm you are editing the correct learner and checklist.
- Changes apply immediately after saving.
- **Validated By** cannot be blank when saving edits.

## Steps

1. Open **Learning > Grade Checklists**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/checklists-edit-validation-details/step-01.png" alt="Learning menu with Grade Checklists option">

2. Search for the learner by first name, last name, or user ID.
3. Select the checklist title.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/checklists-edit-validation-details/step-02.png" alt="Grade Checklist search page with checklist title">

4. At the top of the checklist, select the checklist title to open details.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/checklists-edit-validation-details/step-03.png" alt="Checklist grading page with checklist title">

5. Find the line item and select **Edit** under **Options**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/checklists-edit-validation-details/step-04.png" alt="Checklist line item Options edit button">

6. Update **Validated By**, **Date**, and **Rating** as needed.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/checklists-edit-validation-details/step-05.png" alt="Validation details edit fields">

7. Select **Save**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/checklists-edit-validation-details/step-06.png" alt="Checklist detail page after validation edit">

## Notes

- Use the back button to return to the checklist after saving.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
