# Add an External User

Use this guide to create an external learner profile for someone who needs to attend a class but is not loaded into Cornerstone through the Fairview HR file.

## Before You Begin

- Use this process only for external staff who do not already have a Cornerstone profile.
- Do not manually add Fairview employees. Fairview employees are created by the HR file.
- Search all user statuses before creating a profile so you do not create a duplicate learner.

## Steps

1. Go to **Menu > System Admin > Users**.
2. Search for the learner:
   - Change **User Status** to **All**.
   - Search by last name, first initial, email, or other known criteria.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/admin-add-external-user/step-01.png" alt="Users search page with User Status set to All">

3. If no existing profile is found, select **Add User**.
4. Complete the required user details:
   - **User Name**: use the first part of the learner's email address before `@`.
   - **Active Period Start Date**: use today's date.
   - **Active Period End Date**: set to one month after the class date.
   - **Email Address**: enter the learner's email address.
   - **Division**: select **External**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/admin-add-external-user/step-03.png" alt="Add new user form">

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/admin-add-external-user/step-04.png" alt="Active Period settings for an external user">

5. Select **Save**.

## Notes

- If you find an inactive existing profile, reactivate or update the existing profile instead of creating a duplicate.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
