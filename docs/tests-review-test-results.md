# Review Test Results

Use this guide to review a learner's test score, question details, correct answers, and selected answers.

## Steps

1. Open the learner transcript and search for the test, or find it in the transcript list.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/tests-review-test-results/step-01.png" alt="Learner transcript with test search result">

2. Select **View Training Details**. For completed tests, this may be inside the item dropdown.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/tests-review-test-results/step-02.png" alt="Transcript test item with View Training Details">

   <img class="guide-image guide-image--small" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/tests-review-test-results/step-03.png" alt="Completed test dropdown with View Training Details">

3. In **Scoring Details**, select **Review** under **Review Test**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/tests-review-test-results/step-04.png" alt="Scoring Details section with Review link">

4. Select **Show Details** to view each question, the correct answer, and the learner's selected answer.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/tests-review-test-results/step-05.png" alt="Test review page with Show Details">

## Notes

- Use this review before making any manual transcript or grading changes.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
