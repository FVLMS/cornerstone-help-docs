# How To: Create Evaluation

This guide explains how to add an Evaluation to the LMS. Evaluations can be attached to any training object in Cornerstone, and can be set to optional or required.

## Create a Category and Questions

1. Navigate to Menu > Content Management > Catalog > Evaluations.
2. select the *Question Bank* link.
<img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/ongoing-competency-2026/create-eval-1.png" alt="eval1">
3. select the *Categories* tab and select the *Create New Category* button.
4. Enter the Category name (this should be the Evaluation name) and select the *Save* button.
<img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/ongoing-competency-2026/create-eval-2.png" alt="eval2">
5. select the **Questions** tab and select the *Create New Question* button.
<img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/ongoing-competency-2026/create-eval-3.png" alt="eval3">
6. Enter your test question
7. Select the type of question (Response Type). Response Types include the following: Yes/No, True/False, True/False, Likert Scale, Multiple Choice/Single Answer, Multiple Choice/Multiple Answer, Text Only.
8. Add your response choices (applicable only to Multiple Choice Response Types).
9. Select Multi part option to create sub questions or Enable Comments to have a free text comment box display, if desired.
10. Select the Category created in Step 3.
11. select the *Submit* button.
<img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/ongoing-competency-2026/create-eval-4.png" alt="eval4">
12. Repeat for all questions.

---

## Create the Evaluation

1. Navigate to Menu > Content Management > Catalog > Evaluations.
2. select the *Create New Evaluation* button.
3. Enter the Evaluation Name (it should match the category you created in the previous section).
4. select the *+* button next in the Sections and Questions column header - all evaluations must have at least one section.
5. Enter the Section Title/Instructions and select the "Done" button.
<img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/ongoing-competency-2026/create-eval-5.png" alt="eval5">
6. select the *+?* button in the Options column.
<img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/ongoing-competency-2026/create-eval-6.png" alt="eval6">
7. From the *All Categories* dropdown, select the category you previously created.
8. select the *Search* button.
9. select the *Add All Questions* button.
<img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/ongoing-competency-2026/create-eval-7.png" alt="eval7">
10. select the *Done* button.
11. In the *Response Required* column, select the checkbox to include the desired question(s) in the evaluation.
12. Scroll down and select the *Submit* button.

## Attach the Evaluation to a Training Object

1. Navigate to Menu > Content Management > Catalog > Course Catalog.
2. Search for the Training object title.
3. In the Action column, select the ... > Edit.
4. select the *Evaluations* tab.
5. select the *Customize* link.
6. Enter the title of your Evaluation and select the *Search* button.
7. Check the *Active* and *Required* checkboxes. If the *Required* box is checked, the learning object will not be marked complete **until** the evaluation is completed.
8. select the *Save* button.
