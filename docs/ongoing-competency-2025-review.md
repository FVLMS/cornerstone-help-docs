# Ongoing Competency 2025 Review

Use this checklist to review 2025 ongoing competency curricula and learning objects before assignment.

## Curriculum Review

- **Availability**: confirm the curriculum is available to **Group - All users in Group: 00-Fairview (00ALLFV)** when appropriate.
- **Structure**: confirm sections and items are sequenced so learners can access the right content.
- **Required sections**: set section sequence to `1` unless the curriculum intentionally starts with an optional section.
- **Optional first section**: if the optional section is first, use sequence `1` for optional and `2` for required.
- **Training items**: set training items to sequence `1` within their section unless a different order is intentional.

## Learning Object Review

- Use only supported learning object types: online class, material, note, test, or observation checklist.
- Do not use external learning for ongoing competency.
- For materials:
  - Do not upload content in **Resources**.
  - Use **Material Source** for uploaded files or URLs.
  - Use anonymous links for PolicyTech URLs.
  - Use PDF files for uploaded material.
- For free form essay tests:
  - Add a grader unless the AutoPass process is being used.
  - Use only one question if using AutoPass.
