# Withdraw from a Session

Use this guide to withdraw from a scheduled instructor-led training session.

## Steps

1. Go to **My Transcript**.
2. Find the session.
3. Open the session dropdown and select **Withdraw**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-withdraw-from-session/step-01.png" alt="Transcript session dropdown with Withdraw option">

4. Select a reason, enter comments, and select **Save**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-withdraw-from-session/step-02.png" alt="Withdraw session reason and comment form">

## Notes

- Withdrawing removes the session registration from your transcript status for that session.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
