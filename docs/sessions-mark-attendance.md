# Mark Session Attendance

Use this guide to record attendance and pass status for learners on an instructor-led training roster.

## Before You Begin

- Confirm you are working in the correct event and session date.
- Mark both attendance and pass status carefully. The combination determines the learner's transcript status.
- Roster processing may take up to 15 minutes after submission.

## Steps

1. From the LMS home page, open the main menu.

2. In **Content Management**, select **Manage Events & Sessions**.

   <img class="guide-image guide-image--small" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-mark-attendance/step-02.png" alt="Content Management menu with Manage Events and Sessions">

3. Search for the event by **Event Name**.
4. In the search results, select **View Sessions**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-mark-attendance/step-05.png" alt="Manage Events and Sessions search results with View Sessions">

5. Find the correct session and select **Roster**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-mark-attendance/step-07.png" alt="Session list with Roster action">

6. Open the **Attendance and Scoring** tab.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-mark-attendance/step-08.png" alt="Session Roster page with Attendance and Scoring tab">

7. Mark each learner's attendance and pass status.

| Attendance | Pass | Transcript Status |
| --- | --- | --- |
| Checked | Checked | Complete |
| Checked | Unchecked | Incomplete |
| Unchecked | Checked | No Show |
| Unchecked | Unchecked | No Show |

8. Select **Submit Roster**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-mark-attendance/step-10.png" alt="Attendance and Scoring roster with Submit Roster button">

9. Confirm the roster submission is complete. Allow up to 15 minutes for transcript updates.

## Notes

- If a learner was marked incorrectly, contact the LMS team before making additional transcript changes.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
