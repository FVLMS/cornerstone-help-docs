# Run Standard Reports

Use this guide to run a shared standard report in Reporting 2.0.

## Steps

1. Go to **Menu > Reports > Reporting 2.0**.
2. Open the standard report you need.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/reports-run-standard-reports/step-01.png" alt="Reporting 2.0 shared standard reports list">

3. Enter the report filters, such as users, locations, training titles, or transcript status.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/reports-run-standard-reports/step-02.png" alt="Reporting 2.0 report filter panel">

4. Select **Refresh Report** to generate results.

   <img class="guide-image guide-image--small" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/reports-run-standard-reports/step-03.png" alt="Refresh Report button">

5. If you change filters after the first run, select the refresh icon again.

   <img class="guide-image guide-image--tiny" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/reports-run-standard-reports/step-04.png" alt="Reporting 2.0 toolbar with refresh and export icons">

6. When the report returns the desired results, select the Excel icon to export.

## Notes

- Refresh the report any time you change filters.
- Export to Excel when you need to sort, filter, or save report results outside Cornerstone.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
