# Run the Time Spent Report

Use this guide to report how many minutes a learner spent in individual learning objects such as eLearning, materials, or tests.

## Before You Begin

- The report shows time for individual learning objects.
- Curriculum-level time is not reported as a single total; review the learning objects inside the curriculum instead.

## Steps

1. Go to **Menu > Reports > Reporting 2.0**.

   <img class="guide-image guide-image--small" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/reports-time-spent/step-01.png" alt="Reports menu with Reporting 2.0">

2. In **Shared with Me**, search for **Time Spent**.
3. Open **Common Report: User - Time Spent**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/reports-time-spent/step-02.png" alt="Reporting 2.0 search results for Time Spent report">

4. Select **Select Users**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/reports-time-spent/step-03.png" alt="Time Spent report filters with Select Users button">

5. Select learners:
   - Search for individual learners by first and last name.
   - Use **Filters** for User ID, username, manager name, or other fields.
   - Select **Apply Filters** when using filters.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/reports-time-spent/step-04.png" alt="Select Users search and filter fields">

6. Review selected learners on the **Selected** tab.
7. If a selected learner has subordinates, clear **Include Subordinates** unless you want subordinate data included.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/reports-time-spent/step-05.png" alt="Selected learners tab with Include Subordinates checkbox">

8. Select **Select** at the bottom of the page to return to the report.
9. Select **Refresh Report**.

   <img class="guide-image guide-image--small" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/reports-time-spent/step-06.png" alt="Refresh Report button">

10. Review the report results at the bottom of the page.
11. To export, select the Excel icon in the upper-right report toolbar.

   <img class="guide-image guide-image--small" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/reports-time-spent/step-08.png" alt="Reporting 2.0 toolbar with Excel export icon">

## Notes

- Export to Excel when you need to sort or filter the results.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
