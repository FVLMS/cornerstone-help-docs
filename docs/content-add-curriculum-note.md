# Add a Curriculum Note

Use this guide to add short instructions, links, or context directly inside a curriculum without creating a separate material.

## Before You Begin

- Use a note for curriculum-specific directions or links.
- Use a material instead if the content needs its own transcript record, completion rules, or reuse outside this curriculum.
- If the note includes links, prepare the final link text and destination before editing the curriculum.

## Steps

1. Open the curriculum and go to the **Structure** section.
2. Add or select the content section where the note should appear.
3. Open the section's **ellipses** menu and select **Add Note**.

   <img class="guide-image guide-image--small" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/content-add-curriculum-note/step-01.png" alt="Add Note option in the curriculum section menu">

4. Enter a clear note title.
5. Add the note content in the editor:
   - For plain text, type or paste the instructions in **Design** view.
   - For linked text, build the link in [Word to HTML](https://wordhtml.com/) and paste the generated HTML into **HTML** view.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/content-add-curriculum-note/step-02.png" alt="Curriculum note editor with title and Design or HTML options">

6. If you are using Word to HTML, select the link icon, enter the URL and display text, set **Target** to **New window**, and select **OK**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/content-add-curriculum-note/step-04.png" alt="Insert link window with URL, display text, and target fields">

7. Copy the generated HTML from Word to HTML.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/content-add-curriculum-note/step-05.png" alt="Word to HTML editor with generated HTML available to copy">

8. Return to the Cornerstone note, switch to **HTML** view, paste the HTML, and save the note.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/content-add-curriculum-note/step-06.png" alt="Cornerstone note HTML view with pasted link HTML">

9. Test the note from the assigned curriculum:
   - If the note is required, confirm learners can select **Mark Complete** after reading it.
   - If the note is optional, confirm the note opens and the links work.

## Notes

- Notes work best for brief curriculum-only information. Keep long instructions in a material or PDF.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
