# Auto Assign Dashboard

Use this guide to review which training is assigned to positions and compare assignment rules between areas.

Access the dashboard at <https://fairviewhealth.csod.com/catalog/CustomPage.aspx?id=221000513>.

## Choose a Mode

The dashboard has two working modes:

- **Auto Assignment Listing Tool**: find assignments by area or by training title.
- **Auto Assignment Comparison Tool**: compare two department/job-code combinations.

## Filter by Area

1. In the listing tool, select **Filter by Area**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/admin-auto-assign-dashboard/step-01.png" alt="Auto Assignment Listing Tool with Filter by Area selected">

2. Enter one or more area fields:
   - **Facility Code**
   - **Department Code**
   - **Job Code**
3. Select **Run Report**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/admin-auto-assign-dashboard/step-02.png" alt="Auto Assignment Listing Tool area filters">

4. Review the results table.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/admin-auto-assign-dashboard/step-04.png" alt="Auto assignment listing results">

## Filter by Training

1. Select **Filter by Training**.
2. Enter the full training title or a distinctive part of the title.
3. Select **Run Report**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/admin-auto-assign-dashboard/step-03.png" alt="Auto Assignment Listing Tool with training title filter">

## Compare Two Areas

1. Select **Compare Two Areas**.

   <img class="guide-image guide-image--small" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/admin-auto-assign-dashboard/step-05.png" alt="Compare Two Areas button">

2. Enter **Department Code** and **Job Code** for both areas. All fields are required in comparison mode.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/admin-auto-assign-dashboard/step-06.png" alt="Auto Assignment Comparison Tool filter fields">

3. Select **Run Report**.
4. Review the **Comparison Result** column to see whether the training assignment matches or differs between the two areas.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/admin-auto-assign-dashboard/step-07.png" alt="Auto assignment comparison results">

## Find Position Codes

1. Select **Active Position Listing** if you need facility, department, or job codes.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/admin-auto-assign-dashboard/step-08.png" alt="Active Position Listing button">

2. Use the exported spreadsheet to look up active positions and their associated facility, department, and job codes.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/admin-auto-assign-dashboard/step-09.png" alt="Active Position Listing spreadsheet">

## Notes

- Use **Export to CSV** after running a report if you need to sort, filter, or save the results.
- Use **Clear Filters** before starting a new lookup.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
