# Use the Learning Assignment Tool

Use this guide to create a one-time learning assignment for a group of learners in Cornerstone.

## Before You Begin

- Confirm the training object or objects that should be assigned.
- Confirm the learner population before submitting the assignment.
- Confirm whether the assignment should create a new occurrence for learners who already have the training on their transcript.
- Contact the LMS team at LMS@fairview.org before submitting if the assignment may affect a large group or if the recurrence setting is unclear.

## Steps

1. Go to **Menu > Content Management > Learning Assignment Tool**.
2. Select **Create Assignment**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learning-assignment-tool/step-01.png" alt="Learning Assignment Tool page with Create Assignment highlighted">

3. Enter the assignment **Title** and **Description**.
4. Select **Select Training** and select one or more training objects.
5. Select **Next**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learning-assignment-tool/step-02.png" alt="Assignment General Information and Training Selection areas highlighted">

6. In **Training Assignment Workflow**, select **Assigned, Approved, and Registered** to skip approval workflows.
7. In **Email Settings**, select **Send Assign Training** emails and clear **Send Register Training** emails if learners should receive assignment emails.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learning-assignment-tool/step-03.png" alt="Assignment workflow and email settings highlighted">

8. To send reminder emails before the due date, go to **Custom Emails > Set Custom Emails**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learning-assignment-tool/step-04.png" alt="Custom Emails setting and Set Custom Emails button highlighted">

9. Select the plus icon for **Training is Due**.
10. Select **Active** for **Training is almost DUE - 7 days**.
11. Select **Save**.
12. Select **Next**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learning-assignment-tool/step-05.png" alt="Training is Due email settings with plus icon, Active checkbox, and Save button highlighted">

13. Enter the assignment dates. In most cases, only the due date is needed.
14. Select **Next**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learning-assignment-tool/step-06.png" alt="Assignment date settings with Training Due Date highlighted">

15. Select users or upload a CSV file.
16. Enable **Assign New Occurrence** only when learners should receive a new occurrence of training that is already on their transcript.
17. Select **Generate Initial User List**.
18. Select **Next** after the list is generated.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learning-assignment-tool/step-07.png" alt="User Criteria page with selection controls and Generate Initial User List highlighted">

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learning-assignment-tool/step-08.png" alt="Generate Initial User List button and Next highlighted">

19. Review the initial user list.
20. Confirm the users are correct and check whether learners already have the training on their transcript.
21. Select **Next**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learning-assignment-tool/step-09.png" alt="Initial User List with learner details redacted">

22. Review the final assignment details.
23. Select **Submit** to create the assignment.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learning-assignment-tool/step-10.png" alt="Learning assignment summary with processed count highlighted">

## Notes

- The assignment is created when you click **Submit**. Save a draft or contact the LMS team before that point if the user count seems wrong.
- After submitting, you can review the assignment status and learner progress from the assignment record.
