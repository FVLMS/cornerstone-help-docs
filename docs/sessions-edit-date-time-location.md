# Edit Session Date, Time, or Location

Use this guide to update a session's date, time, or location.

## Before You Begin

- Confirm you are editing the correct event and session.
- Session changes may affect learner calendars, notifications, and attendance expectations.

## Steps

1. Go to **Menu > Content Management > Manage Events & Sessions**.
2. Search for the event.
3. Find the session, open the ellipses menu, and select **Edit Session**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-edit-date-time-location/step-02.png" alt="Manage Events and Sessions page with Edit Session option">

4. In **Parts Schedule**, select **Edit** for the session part.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-edit-date-time-location/step-03.png" alt="Parts Schedule table with Edit option">

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-edit-date-time-location/step-04.png" alt="Edit Part page for a session">

5. To change the location, remove the current location and use the search icon to select the new location.

   <img class="guide-image guide-image--tiny" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-edit-date-time-location/step-05.png" alt="Location field with search icon">

6. To change the date, use the calendar icon.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-edit-date-time-location/step-06.png" alt="Session date picker">

7. To change the time, use the **Start Time** and **End Time** dropdowns.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-edit-date-time-location/step-07.png" alt="Session start time dropdown">

8. Select **Save Part**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-edit-date-time-location/step-08.png" alt="Save Part button">

## Notes

- If the change is close to the session start time, confirm learners and instructors are notified.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
