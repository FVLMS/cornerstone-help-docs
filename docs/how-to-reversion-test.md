# How To: Reversion Test

## Minor Test Edits

You can edit all test options (i.e. review level, passing score, graders, attempt limits) without creating a new version.

1. Navigate to Menu > Content Management > Tests and select the *Tests* link
2. Search for your Test
3. select the *Edit* link on the right side of the test
4. Make your edits and select the *Save* button on the last page

## Minor Question Edits

You can edit the language of a question without creating a new version. Note that your edits *will* apply retroactively for learners who have already completed the test.

1. Navigate to Menu > Content Management > Tests and select the *Tests* link
2. select the *Question Bank* button in the top right
3. Search for your question (use the Category filter to see all questions in your test)
4. select the *Edit* link (sometimes hidden beyind the *three dots* button) on the right side of the question
5. Make your edits and select the *Save* button

## Edits Requiring a New Version

If you want to add or remove questions from the test, or make edits to the structure of a question (changing the correct answer or adding or removing possible answers) you will need to create a new version of the test **AND** manually replace it in every Curriculum it's in.

### Edit/Copy Questions

1. Navigate to Menu > Content Management > Tests and select the *Tests* link
2. select the *Question Bank* button in the top right
3. Search for your question (use the Category filter to see all questions in your test)
4. select the *three dots* button on the right side of the question and select the *Copy* button
5. Make your edits and select the *Save* button
6. Edit the original version of the question, uncheck the "Active" checkbox, and select the *Save* button

### Edit the Test

1. Navigate to Menu > Content Management > Tests and select the *Tests* link
2. Search for your Test
3. select the *Edit* link on the right side of the test
4. Navigate to the *Structure* page
5. If you need to remove an old question, find the question and select the *Delete* link on the right side of the question
6. If you need to add a new/replacement question:
    1. select the *Add Question* button
    2. Search for your question, using the Categories filter if desired
    3. select the *Add* link for the desired question(s)
    4. select the *Done* button
7. select the *Next* button until you reach the *Confirm* page
8. If desired, add a description of your changes to the *Changes Made to this Test* field
9. select the *Finish* button
10. **IMPORTANT:** the new version of your test needs to be replaced in your Curriculum. Follow the steps in the next section for every Curriculum containing this test.

### Replacing the Test in Curriculum

1. Navigate to the Menu > Content Management > Catalog page and select the Curriculum link
2. Search for your curriculum and select the *Edit* button on the right side
3. select the *Structure* page on the left navigation panel
4. Find the test in question and select the *trash can* icon on the right side of the test
5. select the *Add Training* button on the section containing the test
6. Search for your test, select the *Add* link, scroll down and select the *Add* button
7. Check the four boxes on the test

8. Drag the test to the correct position and indentation in the structure
9. Ensure the sequence number is set correctly
10. select the *Save* button
11. If anyone is assignd the Curriculum, you will be given reversion options. Typically you will continue with the default options, which will replace the curriculum version for anyone not completed. If you have questions or are unsure, reach out to LMS@fairview.org.
12. select the *Next* button
13. select the *Save* button
