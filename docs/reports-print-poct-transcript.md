# Print a POCT Transcript Report

Use this guide to export a learner transcript report filtered to POCT items.

## Steps

1. From the learner's transcript, open the transcript report menu and select **Run Transcript Report**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/reports-print-poct-transcript/step-02.png" alt="Transcript report menu with Run Transcript Report option">

2. In the report window, enter **POCT** in **Title**.
3. Check **Include Archived Training** so historical POCT completions are included.
4. Select **Run Report**. The report downloads as an Excel `.xls` file.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/reports-print-poct-transcript/step-03.png" alt="Transcript report filters with POCT title and Include Archived Training">

5. Open the exported report and filter or sort as needed to review completion history.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/reports-print-poct-transcript/step-04.png" alt="Excel POCT transcript report output">

## Notes

- Include archived training when you need a full historical POCT view.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
