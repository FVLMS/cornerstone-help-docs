# Create a Test

Use this guide to create a test in Cornerstone. A test can be used as a standalone learning object or added to a curriculum.

## Before You Begin

- Decide the test title before creating questions.
- Create a question category with the same name as the test so the questions are easy to find later.
- Confirm the question types, correct answers, and answer explanations before building the test.
- Contact the LMS team before limiting availability to specific positions or groups.

## Steps

1. Go to **Menu > Content Management > Test Engine**.
2. Select **Question Bank**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/create-test/step-01.png" alt="Test Engine page with Question Bank highlighted">

3. Open the **Categories** tab and click **Create New Category**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/create-test/step-02.png" alt="Question Bank Categories tab with Create New Category highlighted">

4. Enter the **Category Title**. Use the same name as the test.
5. Select **Save**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/create-test/step-03.png" alt="Add Category form with Category Title and Save highlighted">

6. Return to the **Questions** tab and click **Create New Question**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/create-test/step-04.png" alt="Question Bank Questions tab with Create New Question highlighted">

7. Build the question:
   - Enter the question text.
   - Select the **Response Type**.
   - Add response choices when the response type requires them.
   - Select **Always Display** for each response choice that should always appear.
   - Mark the correct answer.
   - Upload a question image or video if needed.
   - Add an answer explanation if needed.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/create-test/step-05.png" alt="Create Question form with question text, response type, response choices, and answer options highlighted">

8. Select the category you created for this test.
9. Confirm **Active** is selected, then click **Submit**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/create-test/step-06.png" alt="Create Question form with Category and Submit highlighted">

10. Repeat the question steps until all test questions are created.
11. In **Question Bank**, click **Test Engine**.

    <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/create-test/step-07.png" alt="Question Bank page with Test Engine highlighted">

12. On the **Test Engine** page, click **Create New Test**.

    <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/create-test/step-08.png" alt="Test Engine page with Create New Test highlighted">

13. On the **General** page, complete the test details:
    - **Test Name**: use the same name as the question category.
    - **Provider**: select **Fairview eLearning**.
    - **Subjects**: add the appropriate subject.
    - **Attempts Allowed**, review settings, and other options: choose the settings approved for the test.
    - **Instructions**: add learner instructions if needed.
    - **Active**: confirm the test is active when it is ready to use.
14. Select **Next**.

    <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/create-test/step-09.png" alt="Create Test General page with key settings highlighted">

15. On the **Structure** page, add a section. Use the same title as the test when possible.
16. In the section, click **Add Question**.

    <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/create-test/step-10.png" alt="Test Structure section with Add Question highlighted">

17. Search for the category title you created earlier.
18. Select **Add All Questions**.
19. Select **Done**.

    <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/create-test/step-11.png" alt="Add Questions dialog with category search, Add All Questions, and Done highlighted">

20. Select **Next**.
21. On **Availability**, select **All Users** from the dropdown and click **Add**.
22. Select **Next**.
23. Skip **Pricing** by clicking **Next**.
24. Review the **Confirm** page and click **Submit**.

## Notes

- If the test should only be available to certain positions or groups, contact the LMS team before setting availability.
- Keep the question category and test name aligned. This makes future edits, reversioning, and troubleshooting easier.
