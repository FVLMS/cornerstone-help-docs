# View Training Details

Use this guide to open assignment, version, and transcript history for a training item.

## Steps

1. Search for the learner.
2. Open the learner's transcript.
3. Find the training item and select **View Training Details**. If the button is hidden, open the item's dropdown menu.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-view-training-details/step-01.png" alt="Transcript item with View Training Details option">

4. Expand **Assignment and Version History** and **Transcript History** as needed.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-view-training-details/step-02.png" alt="Training Details page with history sections">

## Notes

- Use this view to confirm assignment source, version history, and transcript activity before making manual changes.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
