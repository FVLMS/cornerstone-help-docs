# Print a Transcript Report

Use this guide to run and download a full transcript report from Cornerstone.

## Before You Begin

- **Export to PDF** and **Print Transcript** only print the visible transcript page.
- **Run Transcript Report** is recommended when you need a full report with customizable options.
- The report downloads as an Excel `.xls` file.

## Steps

1. From the home page, click **My Transcript**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/print-transcript-report/step-01.png" alt="Home page tile with My Transcript highlighted">

2. Open the transcript actions menu.
3. Select **Run Transcript Report**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/print-transcript-report/step-02.png" alt="Transcript action menu with Run Transcript Report highlighted">

4. In the transcript report window, keep the default **Training** setting as **All Training** unless you need a narrower report.
5. In the **Date** section, keep the default date option unless another option is needed.
6. In **Advanced**, select **Include Training Detail Information (Credits)** if the report should include contact hours or credit details.
7. Select **Run Report**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/print-transcript-report/step-03.png" alt="Transcript Report window with report options and Run Report highlighted">

## Notes

- The report downloads to your computer as an Excel file.
- Use the full transcript report for personal record keeping when you need more than the visible transcript page.
