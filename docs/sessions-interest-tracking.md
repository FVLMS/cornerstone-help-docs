# Track Interest for Sessions

Use this guide to request email notifications when new sessions become available for an event.

## Set Up Interest Tracking

1. Search for the event from the global search bar and open the event details page.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-interest-tracking/step-01.png" alt="Global search result for an event">

2. Open the **Select a Session** dropdown and choose **Notify Me of New Sessions**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-interest-tracking/step-02.png" alt="Event details page with Notify Me of New Sessions option">

3. Choose the location preference:
   - Select **Select a Location** if you only want notifications for specific locations.
   - Select **Notify me when sessions are scheduled at any location** if any location is acceptable.

   <img class="guide-image guide-image--small" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-interest-tracking/step-03.png" alt="Interest Tracking location preference options">

4. If you chose specific locations, search for each location, select the plus icon to add it, and then select **Done**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-interest-tracking/step-04.png" alt="Location search window for Interest Tracking">

5. Review the Interest Tracking form and select **Submit**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-interest-tracking/step-05.png" alt="Interest Tracking form with selected locations">

6. Use the hospital-site list if you need to confirm location names.

   <img class="guide-image guide-image--small" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-interest-tracking/step-06.png" alt="Hospital site list for Interest Tracking">

## Review or Stop Notifications

1. Go to **Interests and Waitlists** from the main menu.
2. Review your interest details.
3. Use the edit or delete icons to update or stop an interest-tracking notification.

   <img class="guide-image guide-image--small guide-image--phone" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-interest-tracking/step-07.png" alt="Interests and Waitlists menu item">

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-interest-tracking/step-08.png" alt="Interest Details page with edit and delete icons">

## Notes

- Interest tracking sends email notifications when matching sessions are scheduled.
- Interest tracking does not enroll you in a session; you still need to request or register when a session becomes available.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
