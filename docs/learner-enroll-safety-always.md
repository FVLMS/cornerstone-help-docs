# Enroll in Safety Always

Use this guide to self-enroll in an available **Mandatory Safety Always** session.

## Steps

1. In the global search box, search for **Mandatory Safety Always Part** and select the Part 1 or Part 2 result with the calendar icon.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-enroll-safety-always/step-01.png" alt="Global search results for Mandatory Safety Always">

2. Review the available sessions. Use **Show More** if additional sessions are available. Sessions with available seats appear active; full sessions appear unavailable.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-enroll-safety-always/step-02.png" alt="Safety Always session list with available seats">

3. Choose the session you want, then select **View Details** and **Request**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-enroll-safety-always/step-03.png" alt="Safety Always session details with Request option">

4. Return to the home page and confirm the class appears in **Upcoming Sessions**. The update may take 5 to 10 minutes.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-enroll-safety-always/step-04.png" alt="Upcoming Sessions box showing a registered session">

## Notes

- If the session does not appear after several minutes, refresh the page and check your transcript.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
