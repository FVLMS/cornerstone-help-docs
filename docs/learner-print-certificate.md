# Print a Certificate as a Learner

Use this guide to print or save a certificate for a completed online course or class session.

## Steps

1. From the LMS home page, go to **My Transcript**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-print-certificate/step-01.png" alt="My Transcript link from the learner home page">

2. Set **Training Status** to **Completed** to find the completed course or session.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-print-certificate/step-02.png" alt="Transcript filtered to completed training">

3. Select **View Certificate**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-print-certificate/step-03.png" alt="View Certificate button on a completed transcript item">

4. Print or save the certificate from the certificate window.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-print-certificate/step-04.png" alt="Certificate window for a completed learning item">

## Notes

- Certificates are available only after the learning item is complete.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
