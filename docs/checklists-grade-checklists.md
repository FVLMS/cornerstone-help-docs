# Grade Checklists

Use this guide to grade checklist line items for learners in Cornerstone.

## Before You Begin

- Only grade checklist items that were observed or otherwise validated.
- Everyone has permission to grade checklists, but saved checklist grading may not be editable later.
- Many checklists require manager approval after grading is complete.

## Steps

1. Go to **Menu > Learning > Grade Checklists**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/grade-checklists/step-01.png" alt="Learning menu with Grade Checklists highlighted and example user name redacted">

2. Search for the learner by first name, last name, or user ID.
3. If needed, search by checklist title.
4. Select **Search**.
5. Select the checklist you need to grade.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/grade-checklists/step-02.png" alt="Grade Checklists search page with example learner data redacted">

6. Enter a date and rating for each line item that was observed:
   - **Successful** automatically checks the competency row item.
   - **N/A** requires you to manually check the competency row item.
   - **Unsuccessful** disables the competency row item and prevents checklist completion until the rating is changed to **Successful** or **N/A**.
7. Check the competency row item checkbox next to each completed line item.
8. To add comments, click **Observation Notes**.
9. Select **Save** if you need to continue grading later.
10. When all required line items are complete, click **Sign**.

    <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/grade-checklists/step-03.png" alt="Checklist grading page with observation notes, rating, row checkbox, and sign button highlighted">

11. If **Submit For Approval** is visible, click it after signing.

    <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/grade-checklists/step-04.png" alt="Submit For Approval button">

## Notes

- After a row item is saved and locked, you may not be able to edit the grading for that item.
- Contact the LMS team at LMS@fairview.org if a checklist was graded incorrectly or if the approval workflow is unclear.
