# Validation Options

There are many different validation options you can choose to suite your needs.

## Test

- Standard tests with auto-graded response types (Yes/No, Multiple Choice Single Answer, Multiple Choice Multiple Answer).
- Can use tests for case studies, putting the case study text in the body of the questions.

## Graded test

- Free Form Essay questions require manual grading.
- One or more graders must be selected.
- Graders receive email notifications for every pending grading.
- Grading path: Menu > Content Management > Test Grading.
- You can also set the grader as sysadmin and check the auto-grade box. Doing this will result in an automated process marking the learner as passed during a daily run.
    - This is not recommended as it adds complexity, and no checks on what learners actually enter.

## Checklist

- Observation Checklist (allowed learning object type in curriculum).
- Can be graded by anyone except the learner themselves, or limited to a very small group of pre-defined users.
- Can add a link to a resource in the Checklist description for the preceptor/validator to use as a guide.

## Material

- PDF or URL only.
- Can require a signature in addition to the Mark Complete button (though it is cumbersome and unintuitive for the learner).

## eLearning

- Work with the LMS Team to create and publish an elearning lesson.
- Can add test questions to lessons, but can only report on overall score.

## ILT Event

- Learners can be required to go to in-person or virtual instructor-led sessions.
- When they are marked as attended and passed in the roster they are marked complete for the Event in the Curriculum.
- Create your own Events here: [https://fairviewhealth.csod.com/catalog/CustomPage.aspx?id=221000541](https://fairviewhealth.csod.com/catalog/CustomPage.aspx?id=221000541)

## Considerations

### Multi-person sign off

- Can have multiple required checklists added as a single validation option.
- Alternatively, could add directions into a single checklist to have different users validate each line item, but that is harder to manage and track.

### Case Study

- Tests work well since you can get question level data. You can add the case study to the question text, and/or link to it as an optional resource in the Introduction Material.
- You can use an eLearning, which would be more dynamic and interactive for the learner, but you will only be able to report on overall score.

### Manual completion bypass

- If you do not have a Checklist or Event added as an evaluation option, then a peer, manager, educator, admin, etc. will not be able to mark a user complete for the competency.
- In 2025 we received many requests from educators and managers to mark learners complete, but the only validation options given were learner-driven (i.e. tests). If only learner-driven options are given, then only learners are able to complete the competency.
