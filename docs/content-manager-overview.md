# Content Manager Overview

This guide will provide an overview of the newly designed and centralized Content Manager page. The Content Manager page simplifies content management by putting the catalog and allowing for editing, versioning, and creating content in one location. Additionally, new trainings created from this page will follow default templates, which will reduce time and clicks for content creation, further streamlining the process. Below is a guide to the new page that highlights key new features.

Open the menu, expand Content Management, click Catalog, and then find the Content Manager:

## Using the Content Manager

On the Content Manager page, you will see a content search bar, buttons to filter your view by training type and to view the most recent content you have worked on, and below that you will see the content catalog. In the top right is the training creation button.

The default view is filtered to show training you have created.

<img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/content-manager-overview/content-manager02.png" alt="">

Beneath the content creation pages is the newly designed course catalog. Courses can be filtered by type from the buttons shown above, and below they can be sorted along the columns, and there are links to view the course console, edit the training, and perform functions like assign, copy, version, view as learner, and more depending on training type.

<img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/content-manager-overview/content-manager03.png" alt="">

When creating new training, you can access each type of training from the Content Manger page, as shown below.

Each of these options will take you to the default template, provided that the respective learning object type has a default template available. Note that at this time, there is no available default template for curricula, tests, or events.

<img class="guide-image guide-image--phone" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/content-manager-overview/content-manager04.png" alt="">

Creating content from one of the default templates is simplified, with many unnecessary fields hidden and others pre-filled with the most common settings, but still able to be changed if needed. Note that for LO types with no template available will continue to use the current creation page. Two examples of pre-filled fields are shown below:

<img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/content-manager-overview/content-manager06.png" alt="">

Additionally, you can now save any content as a draft before publishing:

<img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/content-manager-overview/content-manager05.png" alt="">
