# How To: Assign

Use the Learning Assignment Tool (LAT) for Ongoing Competency 2025 assignments.

1. Navigate to the Menu > Content Management > Learning Assignment Tool
2. Search for **1558** or **Ongoing Competency 2026: TITLE**
3. select the dropdown and then select the *Copy* button
<img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/ongoing-competency-2026/assign-1.png" alt="assign1">
5. Fill out the Title
6. Select your curriculum:
    1. select the *X* button for the *Cornerstone Content Development Training* placeholder
    2. select the *Select Training* button
    3. Search for the Curriculum
    4. Check the select box for the curriculum and select the *Select* button
7. select the *Next* button until you reach the *Users* page
8. Select the department and job groups:
    1. select the *Select Users* button
<img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/ongoing-competency-2026/assign-2.png" alt="assign2">
    2. select the *Users* dropdown and select the *Group* option
    3. Enter the *Cost Center/Department Code* into the *ID* field, or for a broader search enter the Department Title/Keyword (e.g. "Emergency Room") into the *Search by Title* field
    4. Check the boxes for the appropriate roles and repeat the search as necessary until all areas have been selected
    5. select the *Select* button
<img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/ongoing-competency-2026/assign-3.png" alt="assign3">
9. Review the selected groups to ensure the correct areas are selected
10. select the *Generate Initial User List* button
11. Review the number of users included in the assignment. If it seems too high you may have selected the wrong groups; select the *Save Draft* link at the bottom of the screen and reach out to LMS@fairview.org for review.
<img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/ongoing-competency-2026/assign-4.png" alt="assign4">
12. When satisfied, select the *Next* button
13. Double check the number of assignments seems accurate
14. select the *Submit* button
<img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/ongoing-competency-2026/assign-5.png" alt="assign5">
15. You can review the status of the assignment and progress of completion for learners by clicking on the assignment you just made
<img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/ongoing-competency-2026/assign-6.png" alt="assign6">
