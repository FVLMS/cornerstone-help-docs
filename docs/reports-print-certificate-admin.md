# Print a Certificate as an Admin

Use this guide to print a learner's certificate from the learner transcript.

## Before You Begin

- Confirm you are viewing the correct learner.
- This workflow is commonly used for external staff or learners who do not access Cornerstone directly.

## Steps

1. Search for the learner.
2. Open the learner's transcript.
3. Find the completed training item and select **Print Certificate**. If the button is hidden, open the item's dropdown menu.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/reports-print-certificate-admin/step-01.png" alt="Transcript item with Print Certificate option">

## Notes

- If **Print Certificate** is not available, confirm the item is complete and certificate-enabled.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
