# Use the Cornerstone Mobile App

Use this guide to install the Cornerstone Galaxy mobile app, sign in, and understand the main learner features.

## Install the App

Scan the QR code for your device type, or search for **Cornerstone Galaxy** in your device's app store.

<img class="guide-image guide-image--small" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-mobile-app/step-01.png" alt="Cornerstone Galaxy iOS app QR code">

<img class="guide-image guide-image--small" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-mobile-app/step-02.png" alt="Cornerstone Galaxy Android app QR code">

## Sign In

1. Open the app and enter **fairviewhealth** as the portal.
2. Select **Alternative Login Method**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-mobile-app/step-03.png" alt="Cornerstone Galaxy portal screen with fairviewhealth entered">

3. Select **Log In With SSO** to use your Fairview credentials.

   <img class="guide-image guide-image--small guide-image--phone" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-mobile-app/step-04.png" alt="Cornerstone Galaxy login method screen with SSO option">

4. Sign in with your Fairview email address and password.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-mobile-app/step-05.png" alt="Fairview sign-in screen in the mobile app">

5. Use **Log In With Credentials** only if you need to sign in with LMS credentials instead of Fairview SSO.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-mobile-app/step-06.png" alt="Log In With Credentials screen">

6. When prompted, enable biometrics or create a 6-digit PIN for future sign-ins.

   <img class="guide-image guide-image--small" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-mobile-app/step-07.png" alt="Face ID prompt in the Cornerstone mobile app">

   <img class="guide-image guide-image--small guide-image--phone" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-mobile-app/step-08.png" alt="Set a PIN screen in the Cornerstone mobile app">

## Use the App

1. Use the home page to continue assigned training and view assigned-training status.

   <img class="guide-image guide-image--phone" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-mobile-app/step-09.png" alt="Cornerstone mobile app learner home page">

2. Use **Search** to find learning content, launch training, or request available sessions.

   <img class="guide-image guide-image--phone" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-mobile-app/step-10.png" alt="Cornerstone mobile app search page">

3. Use **My Learning** as the mobile version of your transcript. Filter by active, completed, or archived learning from the dropdown.

   <img class="guide-image guide-image--phone" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-mobile-app/step-11.png" alt="Cornerstone mobile app My Learning page">

4. If you are an approver, use **Approvals** to approve, deny, or defer training requests.

   <img class="guide-image guide-image--phone" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-mobile-app/step-12.png" alt="Cornerstone mobile app Approvals page">

## Enroll or Withdraw from a Session

1. Search for the event and open the event card.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-mobile-app/step-13.png" alt="Mobile app event search results for BLS Review">

2. Select the session's three-dot menu and choose **Request**.

   <img class="guide-image guide-image--phone" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-mobile-app/step-14.png" alt="Available sessions list in the mobile app">

3. To withdraw from an enrolled session, go to **My Learning**, open the session's three-dot menu, select **Withdraw**, choose a withdrawal reason, and submit.

   <img class="guide-image guide-image--phone" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-mobile-app/step-15.png" alt="Withdraw Registration form in the mobile app">

   <img class="guide-image guide-image--phone" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-mobile-app/step-16.png" alt="My Learning page with session actions menu">

## Use QR Codes for ILT Attendance

1. Open **More > Scan QR Code**.

   <img class="guide-image guide-image--phone" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-mobile-app/step-17.png" alt="More menu with Scan QR Code option">

2. Use the **Scan** tab to scan the session-part QR code. Learners must scan each session part separately.

   <img class="guide-image guide-image--phone" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-mobile-app/step-18.png" alt="Scan QR Code camera screen">

3. Use **My QR Code** if an instructor needs to scan your learner QR code for attendance.

   <img class="guide-image guide-image--phone" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-mobile-app/step-19.png" alt="Learner personal QR code screen">

4. Instructors with ILT permissions can use **Instructor** to scan learner QR codes for sessions scheduled that day.

   <img class="guide-image guide-image--phone" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-mobile-app/step-20.png" alt="Instructor QR code session list">

## Notes

- If you have only the default temporary LMS password, sign in to Cornerstone on a desktop first and set a new password before using **Log In With Credentials**.
- If a QR code is scanned outside the allowed time window, the app displays an expired-code error.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
