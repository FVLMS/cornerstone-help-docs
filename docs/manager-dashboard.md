# Manager Dashboard

Use this guide to open the Manager Dashboard and refresh or export dashboard tile details.

## Steps

1. Go to **Menu > Reports > Dashboards**.
2. Open the **Options** dropdown in the upper-right corner and refresh the dashboard tiles.

   <img class="guide-image guide-image--small" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/manager-dashboard/step-01.png" alt="Manager Dashboard Options menu">

3. Use each tile's dropdown to select **View Details** or **Export to Excel**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/manager-dashboard/step-02.png" alt="Manager Dashboard tile options">

## Notes

- Refresh tiles before using the dashboard for current learner status.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
