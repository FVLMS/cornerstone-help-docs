# Grade a Free Form Essay

Use this guide to grade a pending free form essay response.

## Before You Begin

- Graders receive an email when a test response is waiting for grading.
- The response stays on the pending grading page until a score is submitted.

## Steps

1. Go to **Menu > Content Management > Test Grading**.

   <img class="guide-image guide-image--small" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/tests-grade-free-form-essay/step-01.png" alt="Content Management menu with Test Grading option">

2. Review the list of learners with pending test grading.
3. Select **View Details** for the learner response you need to grade.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/tests-grade-free-form-essay/step-02.png" alt="Pending test grading list with View Details">

4. Review the learner's response, enter the score, and select **Submit**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/tests-grade-free-form-essay/step-03.png" alt="Free form essay grading page with Submit button">

## Notes

- Confirm the score before submitting. Submitted grading updates the learner's test status.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
