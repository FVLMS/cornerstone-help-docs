# Ongoing Competency 2025 Learning Assignment Tool

Use this guide to assign 2025 ongoing competency curricula with the Learning Assignment Tool.

## Before You Begin

- Identify the site, area, and role for the assignment.
- Select all curricula that apply to the same site, area, and role in one assignment rather than creating separate assignments for each curriculum.
- Review the generated user list before submitting. Submitting creates the assignment.

## Steps

1. Go to **Menu > Content Management > Learning Assignment Tool**.
2. Select **Create Assignment**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/ongoing-competency-2025-learning-assignment-tool/step-01.png" alt="Learning Assignment Tool page with Create Assignment button">

3. Enter the assignment title and description:
   - **Title**: `Ongoing Competency 2025: Site/Area/Role`
   - **Description**: optional
   - Do not include each curriculum name in the assignment title.
4. Select **Select Training** and choose all applicable curricula for the site, area, and role.
5. Select **Next**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/ongoing-competency-2025-learning-assignment-tool/step-02.png" alt="Assignment training selection page">

6. Select **Assigned, Approved, and Registered** to skip approval workflows.
7. Check **Send Assign Training** emails and clear **Send Register Training** emails.
8. Select **Next**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/ongoing-competency-2025-learning-assignment-tool/step-03.png" alt="Assignment workflow and email settings">

9. Enter the assignment dates. Usually only a due date is needed.
10. Select **Next**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/ongoing-competency-2025-learning-assignment-tool/step-04.png" alt="Assignment date settings">

11. Select users by group:
    - Select **Select Users**.
    - Change the filter from **Users** to **Group**.
    - Select **Filter** if the ID field is not visible.
    - Search the group ID. Example: `101205040` for UMMC Nursing FP, or `5040` for Nursing FP across facilities.
    - Select the correct group or groups and select **Select**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/ongoing-competency-2025-learning-assignment-tool/step-05.png" alt="Select Users group filter">

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/ongoing-competency-2025-learning-assignment-tool/step-06.png" alt="Group search results for assignment users">

12. Select **Generate Initial User List**.
13. Review the user list. Only learners matching the selected constraints should appear.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/ongoing-competency-2025-learning-assignment-tool/step-07.png" alt="Generated initial user list">

14. Select **Next**.
15. Review the final assignment details.
16. Select **Submit** to create the assignment.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/ongoing-competency-2025-learning-assignment-tool/step-08.png" alt="Final assignment review page">

## Notes

- Groups are updated daily and include primary positions, dual roles, and learner-link information.
- After submission, open the assignment record to review assignment status and learner progress.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
