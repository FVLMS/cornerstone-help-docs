# Create Materials with No Signature Required

Use this guide to turn off the electronic signature requirement for a material.

## Before You Begin

- Materials require an electronic signature by default in some Cornerstone setups.
- Turn the signature off when learners only need to review the material and select **Mark Complete**.
- Keep the signature requirement only when the learning record needs an explicit learner signature.

## Steps

1. After creating or updating the material, go to **Menu > Content Management > Catalog > Course Catalog**.
2. Search for the material title.
3. In the **Actions** column, open the ellipses menu and select **Edit**.

   <img class="guide-image guide-image--small" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/content-materials-no-signature-required/step-02.png" alt="Course Catalog Actions menu with Edit option">

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/content-materials-no-signature-required/step-03.png" alt="Course Catalog search results for the material">

4. On the **General** tab, scroll to the bottom of the page.

   <img class="guide-image guide-image--small" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/content-materials-no-signature-required/step-04.png" alt="Material edit General tab">

5. Clear **Required Electronic Signature**.

   <img class="guide-image guide-image--small" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/content-materials-no-signature-required/step-05.png" alt="Required Electronic Signature checkbox cleared">

6. Select **Save**.

## Notes

- After this change, learners complete the material by selecting **Mark Complete** instead of signing.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
