# Upload a Pharmacy Certification

Use this guide to submit a pharmacy immunization certification record through the Pharmacy Certification Upload tool.

## What the Tool Does

One submission completes the workflow that would otherwise require several manual steps:

- Assigns the appropriate immunization training record in the LMS.
- Marks the training complete on the user's transcript.
- Adds the user to the matching dynamic certification group.
- Uploads the certificate to the [LMS Public Pharmacy Certifications](https://mnfhs.sharepoint.com/:f:/r/sites/LMSTeam/LMS%20Public/Pharmacy%20Certifications?csf=1&web=1&e=kY7cam) library with a standardized filename.

## Submit a Certification

1. Search for the employee.
   - Choose **Last Name** or **User ID**.
   - Use **User ID** when possible because it is the most precise search.
   - Enter the name or ID and select **Search**.
   - Select the correct user from the dropdown. If the dropdown does not appear, try a more specific search.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-pharmacy-certification-upload/step-01.png" alt="Pharmacy Certification Upload employee search">

2. Select the certification type:
   - **Pharmacist Immunization Training Record**
   - **Technician Immunization Training Record**
   - **Technician Immunization Training Record APhA**

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-pharmacy-certification-upload/step-02.png" alt="Pharmacy certification type dropdown">

3. Enter the completion date. Use the date the training was actually completed.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-pharmacy-certification-upload/step-03.png" alt="Completion date calendar for pharmacy certification upload">

4. Attach the completion certificate.
   - Select **Choose File**.
   - Upload the scanned certificate or image as a PDF, JPG, or PNG.
   - You do not need to rename the file. The system renames it when it arrives in SharePoint.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-pharmacy-certification-upload/step-04.png" alt="Attach completion certificate upload field">

5. Select **Submit**.
6. Wait for the processing message. Do not refresh the page.
7. Confirm the green success message appears before leaving the page.

## Verify the Upload

1. Open the user's transcript and find the completion item.
2. Select **View Training Details**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-pharmacy-certification-upload/step-05.png" alt="Transcript item with View Training Details for certification record">

3. Open **Observation History**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-pharmacy-certification-upload/step-06.png" alt="Training details page with Observation History">

4. Confirm the observation history shows the submitter and the SharePoint certificate link.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/learner-pharmacy-certification-upload/step-07.png" alt="Observation History showing uploaded certificate link">

## Notes

- The standardized SharePoint filename follows the employee and certification title.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
