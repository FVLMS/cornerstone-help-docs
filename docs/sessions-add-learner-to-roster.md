# Add a Learner to a Session Roster

Use this guide to add one learner to an instructor-led training session roster.

## Before You Begin

- Confirm the correct event and session date before adding the learner.
- Check the enrollment count and registration deadline. Do not add learners to a full session or a session past the registration deadline unless the LMS team has approved it.

## Steps

1. Go to **Menu > Content Management > Manage Events & Sessions**.
2. Enter the event title in **Event Name** and select **Search**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-add-learner-to-roster/step-01.png" alt="Manage Events and Sessions search fields">

3. Find the event and select **View Sessions**.
4. Find the correct session and select **Roster**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-add-learner-to-roster/step-02.png" alt="Session list with enrollment count and Roster action">

5. Select **Add Users**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-add-learner-to-roster/step-03.png" alt="Roster page with Add Users button">

6. Search for the learner, select **Add**, and then select **Done**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-add-learner-to-roster/step-04.png" alt="Select User window with Add and Done controls">

7. Review the pending learner and select **Add Pending Users to Roster**.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-add-learner-to-roster/step-05.png" alt="Roster page with pending learner and Add Pending Users to Roster button">

8. Confirm the learner is registered and that the learner and manager receive the registration email.

## View Registration Details

1. Search for the event from the global search bar.
2. Open the event details and review the **Register** information by date and time.

   <img class="guide-image" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-add-learner-to-roster/step-06.png" alt="Event detail page with registration dates">

   <img class="guide-image guide-image--small" src="https://mnfhs.sharepoint.com/sites/LearningManagementSystem/Shared%20Documents/cornerstone-help-docs/sessions-add-learner-to-roster/step-07.png" alt="Register by date and time details">

## Notes

- This page is the single-learner version of the roster workflow.
- Contact the LMS team at LMS@fairview.org if you have questions about this process.
