# Password Troubleshooting

Use this guide when you cannot sign in to Cornerstone or the Cornerstone mobile app.

## Before You Begin

- Use your Fairview email address and Fairview password when signing in with SSO.
- If you are using the mobile app, enter **fairviewhealth** as the portal before choosing a sign-in method.
- Use **Log In With Credentials** only when you need to sign in with LMS credentials instead of Fairview SSO.

## Steps

1. Try signing in from the desktop Cornerstone site with your Fairview email address and password.
2. If you only have the default temporary LMS password, sign in to Cornerstone on a desktop first and set a new password before using **Log In With Credentials** in the mobile app.
3. If the issue is with a Lippincott Professional Development profile, use the Lippincott **Forgot Password?** option.
4. If you are still blocked, contact the LMS team at LMS@fairview.org and include the sign-in method, error message, and whether you are using desktop or mobile.

## Notes

- A Fairview network password issue may need to be resolved outside Cornerstone.
- Include the training title if the sign-in issue happens while launching a specific course.
